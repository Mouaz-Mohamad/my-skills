# Dart & Study Skills Pack v2

حزمة موحدة للبرمجة وإدارة Dart + الدراسة والثانوية الأزهرية.

## محتويات الحزمة
- إجمالي المهارات: **150 SKILL.md**
- مهارات V1 الأصلية في الحزمة: **96**
- إضافات V2 الجديدة: **54**
  - **33** مهارة دراسة وثانوية أزهرية
  - **16** مهارة Automation / Security / Data / UI
  - **5** مهارات فيديو متقدمة

## أهم إضافة في V2
`08-study-azhar/azhar-third-secondary-study-master/SKILL.md` هو الـRouter الرئيسي للدراسة.
المسار المقترح لأي درس أو امتحان:

شرح/تشخيص → Retrieval Practice → مسائل أو أسئلة متدرجة → تصحيح → Gap Analysis → Error Log → Spaced Review → Re-test
